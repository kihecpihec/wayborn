# Milestone submission checklist

Local documentation does not prove submission or remote CI success.

- [x] Project definition, MVP scope, scenarios, mockups, architecture and development plan.
- [x] Repository exists at https://github.com/kihecpihec/wayborn.
- [x] Both team members had access when the original milestone was prepared.
- [x] Initial issues and CI workflow were prepared.
- [ ] Obtain the course assistant's GitHub username and grant access through Hanan.
- [ ] Publish changes to the submission branch and verify a successful Actions run.
- [ ] Confirm this milestone's deadline; 11 November 2026 referred to the initial idea.
- [ ] Confirm current remote issue assignments match the local responsibility swap.

Before submission the owner verifies access, assigned issues, CI results, and the
repository link. Export PDF only if required by the course; Markdown/HTML are sources.
